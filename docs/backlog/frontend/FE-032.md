# FE-032 — E2E Test Suite

**Epic:** TESTING  
**Priority:** P1  
**Status:** NOT_STARTED  
**Parallel-safe:** NO — requires all feature tickets complete and a working backend (or comprehensive mock)  

---

## Product Requirement

The 7 critical user flows defined in the implementation plan must be verified end-to-end in both English and Spanish before launch. These flows span multiple pages and involve OAuth, Stripe, and agent actions — unit tests cannot catch the integration failures.

## Current State

No E2E tests exist. No test framework (Playwright) is configured.

## Target State

Playwright configured. Critical flows tested in EN and ES. Tests run against a test/staging backend or a comprehensive mock server.

## Scope

**Install:**
- `@playwright/test`
- Add `"test:e2e": "playwright test"` to `package.json`
- Create `playwright.config.ts`

**Critical flows to test (both EN and ES):**

| Flow | Test |
|------|------|
| **Flow A** | Public landing → switch to ES → Google auth → Gmail connect → Investigation → Results |
| **Flow B** | Free user → locked discovery → upgrade → Stripe mock → return → Pro activated → discoveries unlocked |
| **Flow C** | Pro user → discovery with date → "Remind me" → set reminder → confirmation |
| **Flow D** | Pro user → meeting discovery → Calendar connect → availability → create meeting |
| **Flow E** | Pro user → Ask Detective → Spanish response → open linked discovery |
| **Flow F** | Authenticated user → Settings → change language to ES → UI updates |
| **Flow G** | Sign out → public site stays in ES (localStorage) |

**Additional P1 E2E tests:**
- Auth expiration handling (401 mid-session)
- Post-upgrade context restoration (reminder flow survives payment)
- Gmail disconnect → redirect to onboarding
- Language selector on landing page switches all copy

**Test environment:**
- Primary: test environment pointing at staging backend
- Fallback: Playwright with MSW (Mock Service Worker) intercepting API calls
- Stripe: use Stripe test mode with test card numbers

## Out of Scope

- Full regression test suite (post-launch)
- Cross-browser testing (Chrome/Chromium only for V1)
- Performance testing

## Dependencies

All feature tickets must be complete. Backend test/staging environment must be available.

## Agent Notes

- E2E tests for OAuth flows (Google auth, Gmail connect) require test accounts or OAuth bypass — coordinate with backend team on test credential setup.
- Stripe E2E: use Stripe test mode. The test card `4242 4242 4242 4242` triggers a successful payment.
- For language-switch tests, use Playwright's `page.evaluate(() => localStorage.setItem('inbox-detective-locale', 'es'))` to set locale before navigation rather than clicking through UI each time.
- MSW fallback: if backend is unavailable, use `msw` to mock all API endpoints in Playwright. Define handlers in `e2e/fixtures/handlers.ts`.
