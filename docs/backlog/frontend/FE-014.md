# FE-014 — Discovery Detail + Email Drawer

**Epic:** DISCOVERIES  
**Priority:** P0  
**Status:** NOT_STARTED  
**Parallel-safe:** NO — depends on FE-005, FE-011, FE-012, FE-027  

---

## Product Requirement

Users must be able to understand exactly why a discovery was flagged, see the source email as evidence, and take action. The detail page answers: What happened? Why? What's the evidence? What can I do? Email content must be displayed safely (sanitized) — Inbox Detective must never be an XSS vector.

## Current State

`src/pages/discoveries/DiscoveryDetailPage.tsx` is a placeholder from FE-003. No email drawer exists.

## Target State

- Full discovery detail page at `/app/discoveries/:id`
- Source evidence drawer with safe email content display
- All action handlers (dismiss, feedback, remind, view_source)
- Placeholders for Pro actions (remind, find_time) that trigger RequiresPro gate
- All copy translated in EN and ES

- Discovery feedback: thumbs up/down (Useful / Not useful / Never show this type)

**Create `src/components/EmailDrawer.tsx`:**
```tsx
interface EmailDrawerProps {
  discoveryId: string;
  isOpen: boolean;
  onClose: () => void;
}
```
- Slide-in from right (fixed overlay, not a modal)
- Header: "Source email" + close button
- Loads `useDiscoverySource` when opened (`enabled: isOpen`)

## Agent Notes

- **DOMPurify is a P0 security requirement.** Never render email content (even excerpts) without sanitizing. See FE-027. If FE-027 is not complete when this ticket starts, install `dompurify @types/dompurify` as part of this ticket.
- `title` and `summary` are AI-generated — render them as plain text, not through `t()`. They arrive in the user's locale from the backend.
- The source email `excerpt` from the API is evidence — display it in its original language. Do NOT translate it.
- `EmailDrawer` must NOT render a full Gmail-like email interface. It shows the relevant excerpt and a link to open in Gmail.
- For accessibility: `EmailDrawer` must manage focus (open → focus close button, close → return focus to trigger).
