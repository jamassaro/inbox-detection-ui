## Product Requirement

Calendar scheduling, email drafting, and future agent actions follow a consistent state machine: thinking → proposing → waiting for approval → executing → verifying → done/failed. This pattern must be a single reusable component, not reinvented per feature. Users must always understand what the Detective is doing and confirm consequential actions.

## Current State

No agent action panel exists. This is entirely new.

## Target State

- `AgentActionPanel` component implements the full 8-state machine
- Reused by: calendar scheduling (FE-021), reminder creation (FE-020), email sending
- Consequential actions (send email, create event) require Level 3 explicit confirmation
- All states translated in EN and ES

## Scope

**Create `src/components/AgentActionPanel.tsx`:**

```typescript
type AgentActionState =
  | 'idle' | 'thinking' | 'proposing' | 'approving'
  | 'executing' | 'verifying' | 'done' | 'failed';

interface AgentActionPanelProps {
  state: AgentActionState;
  // Proposing state
  proposal?: ReactNode;
  onSelectProposal?: (selection: unknown) => void;
  // Approving state
  approvalDescription?: string;  // "Create meeting Tuesday at 2:00 PM?"
  approvalLevel?: 2 | 3;         // Level 2 = standard, Level 3 = destructive/send
  onApprove?: () => void;
  onCancel?: () => void;
  // Done state
  resultSummary?: ReactNode;
  // Failed state
  errorMessage?: string;
  onRetry?: () => void;
  // Labels (all optional — defaults from translation keys)
  thinkingLabel?: string;
  executingLabel?: string;
  verifyingLabel?: string;
}
```

State rendering:
- `idle`: renders nothing (or children passed to it)
- `thinking`: animated indicator + `t('detective.agentStates.thinking')`
- `proposing`: renders `proposal` ReactNode (e.g., list of time slots)
- `approving`: approval card with `approvalDescription` + [Confirm] [Cancel]
  - Level 3: confirm button is red/destructive with extra visual weight
- `executing`: progress indicator + `t('detective.agentStates.executing')`
- `verifying`: `t('detective.agentStates.verifying')`
- `done`: `resultSummary` ReactNode
- `failed`: error message + optional retry button

The parent component manages state transitions — `AgentActionPanel` is a pure presenter.

## Agent Notes

- `AgentActionPanel` is a pure presenter component — it holds NO state and makes NO API calls. All state management is in the parent (calendar page, reminder modal, etc.).
- Level 3 confirmation is visually unmistakable. Never make "Send email" look like a harmless navigation button. Use red background, bold text, and possibly an extra confirmation label.
- The `thinking` animation must respect `prefers-reduced-motion: reduce` — use `@media (prefers-reduced-motion)` in CSS or Tailwind's `motion-safe:` prefix.
- Do NOT expose internal agent reasoning. Show status and outcome only.
