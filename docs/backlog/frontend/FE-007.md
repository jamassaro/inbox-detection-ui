## Product Requirement

Users authenticate via Google. The frontend initiates the OAuth flow by redirecting to the backend's Google auth endpoint. The backend handles the OAuth exchange and sets an httpOnly session cookie. The frontend receives the result via a redirect back to `/auth/callback`.

## Current State

`src/pages/AuthCallbackPage.tsx` is a placeholder from FE-003. No Google Sign-In trigger exists anywhere. The landing page CTAs have no auth behavior.

## Target State

- Clicking "Investigate my inbox" / "Sign in" on the landing page initiates Google OAuth
- `AuthCallbackPage` correctly handles the return, resolves the session, and redirects to the appropriate page
- Loading and error states are handled gracefully in both EN and ES

```typescript

    // Store returnPath in sessionStorage before redirect
```

**Implement `src/pages/AuthCallbackPage.tsx`:**
- Shows a loading state ("Signing you in...")
- Calls `GET /auth/me` via TanStack Query to verify session
- On success:
  - If Gmail not connected (`gmailConnected: false` on user) → redirect to `/onboarding`
  - If Gmail connected → redirect to `/app/dashboard`
  - If `returnPath` in sessionStorage → navigate there instead
- On failure:
  - Show error message with retry CTA
  - "Try again" → navigate to `/`

**Wire CTAs on landing page (`src/pages/LandingPage.tsx`):**
- "Investigate my inbox" and "Sign in" buttons call `startGoogleAuth()`
- Pass `returnPath: '/app/dashboard'` (or current path if on a discovery page)

## Agent Notes

- The OAuth flow is a **full page redirect** (`window.location.href = ...`), NOT a fetch/XHR. The browser must follow the redirect chain for the cookie to be set correctly.
- Store `returnPath` in `sessionStorage` (not localStorage) — it should not persist beyond the current tab session.
- `GET /auth/me` after callback does NOT need to be called in a `useEffect` manually — use TanStack Query with `enabled: true` and redirect in the `onSuccess` callback.
- Do NOT add a "Continue with Google" button that renders a Google-styled button — just use the existing `ActionButton` component with the Google icon from Lucide.
- If `VITE_API_BASE_URL` is not set, `startGoogleAuth` must log a clear error and not navigate to an undefined URL.
