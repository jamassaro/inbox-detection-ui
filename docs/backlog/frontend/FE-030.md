## Product Requirement

All 24 locale files must be fully populated with production-quality copy before launch. Stub text from FE-002 must be replaced. All Spanish translations must be reviewed for accuracy and tone.

## Current State

FE-002 creates 24 locale files with stub keys. Each subsequent ticket adds keys as components are built. After all component tickets complete, there will be incomplete, placeholder, or machine-translated strings in both locale files.

## Target State

- All 12 EN namespace files contain complete, production-quality English copy
- All 12 ES namespace files contain complete, accurate Spanish translations
- No untranslated keys (no EN strings showing in ES locale)
- Interpolation variables verified (`{{name}}`, `{{count}}`, `{{date}}`, etc.)
- i18next `missingKeyHandler` does not fire in either locale during critical flows

## Scope

**Audit all 24 locale files:**
- Compare EN and ES files — every key in EN must have a corresponding key in ES
- Flag any missing keys
- Replace all placeholder/stub values with production copy

**Key areas to verify (high risk for missing translations):**
- `detective.json` — AI state labels, chat suggestions (often added last)
- `errors.json` — error codes must map to all backend error codes actually returned
- `billing.json` — all payment state copy (checkout, activating, failed, pending, cancelled)
- `calendar.json` — meeting flow states
- `reminders.json` — confirmation copy with date interpolation

**Spanish translation quality:**
- `public.hero.title`: "Tu bandeja de entrada sabe cosas que tú no."
- `public.hero.investigateCta`: "Investigar mi bandeja"
- `billing.plans.proMonthly`: "$5.99/mes"
- `billing.plans.proAnnual`: "$49/año"
- `settings.deleteAccount.confirmWord`: "eliminar"
- `onboarding.connectGmail.*`: accurate description of Gmail access requested

**Add a missing key check:**
In development mode, configure i18next `missingKeyHandler` to console.warn. Run through all critical flows in Spanish and confirm no warnings appear.

## Agent Notes

- This ticket is a content/translation pass, not a code change. The only code change is verifying the `missingKeyHandler` is active in development.
- Machine translation (e.g., via Google Translate) is acceptable for a first pass, but all customer-facing copy should be reviewed by a Spanish speaker before launch.
- Pay particular attention to formal vs informal register in Spanish. "Tú" (informal) is more appropriate for a consumer product than "Usted" (formal).
- Do NOT change translation key names — only the values. Changing key names would break all components.
