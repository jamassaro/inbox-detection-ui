# FE-025 — Subscriptions Page

**Epic:** SUBSCRIPTIONS  
**Priority:** P1  
**Status:** NOT_STARTED  
**Parallel-safe:** NO — depends on FE-001, FE-004, FE-005, FE-012  

---

## Product Requirement

Subscriptions are a top-level product value. Users should be able to see all detected subscriptions — what they're paying, at what frequency, when they renew, and the annualized cost. Price change history makes Inbox Detective's memory visible.

## Current State

`src/pages/SubscriptionsPage.tsx` is a placeholder from FE-003.

## Target State

- Subscriptions page lists all detected subscriptions from `GET /subscriptions`
- Monthly total and annual total summary at top
- Each subscription shows provider, amount, frequency, renewal date, price change history
- Translated in EN and ES

## Scope

**Create `src/types/index.ts` additions:**
```typescript
interface Subscription {
  id: string;
  company: string;
  companyInitials: string;
  product?: string;
  currentAmount: number;
  currency: string;
  frequency: 'monthly' | 'annual' | 'weekly';
  nextRenewal?: string;      // ISO 8601
  previousAmount?: number;   // if price changed
  priceChangedAt?: string;
  discoveryId?: string;      // linked discovery
}
```

**Create `src/hooks/useSubscriptions.ts`:**
```typescript
// GET /subscriptions → Subscription[]
```

**Implement `src/pages/SubscriptionsPage.tsx`:**
- Summary row:
  - Total monthly: `formatCurrency(monthlyTotal, 'USD', locale)` + "/month"
  - Total annual: `formatCurrency(annualTotal, 'USD', locale)` + "/year"
  - Computed from subscription list (monthly totals aggregated)
- Subscription list (reuse `DiscoveryListItem` pattern or create `SubscriptionListItem`):
  - Company name + initials avatar
  - Product/plan name
  - `formatCurrency(currentAmount, currency, locale)` + frequency label
  - Renewal date: `formatDate(nextRenewal, locale)` (conditional)
  - Price change badge (red) if `previousAmount` present
  - Click → navigate to linked `Discovery` detail if `discoveryId` exists
- Empty state: "No subscriptions detected yet. Run an investigation to find them."
- Loading: `SkeletonListItem` × 5
- Error: `ErrorState` with retry

## Agent Notes

- Monthly totals must handle `annual` frequency subscriptions by dividing by 12. Annual totals must annualize `monthly` subscriptions by multiplying by 12.
- `currency` may vary per subscription (though USD is most common for V1). Always pass the subscription's `currency` field to `formatCurrency`.
- Frequency labels: `t('billing.frequency.monthly')`, `t('billing.frequency.annual')` — same keys used in billing pages.
