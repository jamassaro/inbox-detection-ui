# FE-018 — Billing Settings Page

**Epic:** PAYMENTS  
**Priority:** P0  
**Status:** NOT_STARTED  
**Parallel-safe:** NO — depends on FE-001, FE-004, FE-017  

---

## Product Requirement

Pro users need to see their subscription status and manage their billing (update payment method, view invoices, cancel). Inbox Detective does not rebuild Stripe's billing UI — it links to the Stripe Customer Portal. Free users see their plan status and an upgrade CTA.

## Current State

`src/pages/settings/BillingPage.tsx` is a placeholder from FE-003.

## Target State

- Billing page shows current plan, renewal date, and status
- Pro users can open Stripe Customer Portal
- Free users see plan status + upgrade CTA
- Cancellation state ("cancels at period end") is handled
- Translated in EN and ES

## Scope

**Create `src/hooks/useBillingStatus.ts`:**
```typescript
// GET /billing/status
// Returns { plan, status, renewalDate?, cancelAtPeriodEnd }
```

**Implement `src/pages/settings/BillingPage.tsx`:**

Free user view:
- Current plan: "Free"
- Features not included (list)
- CTA: "Upgrade to Pro" → `useUpgradeRedirect` with `source: 'billing_page'`

Pro user view:
- Current plan: "Pro"
- Status: Active / Cancelling / Expired
- Renewal date: `formatDate(renewalDate, locale)` or "Ends [date]" if cancelling
- Monthly cost / annual cost
- "Manage subscription" button → `POST /billing/portal-session` → full page redirect to Stripe portal
- If `cancelAtPeriodEnd === true`: show "Your subscription ends [date]" warning banner

**Create `src/hooks/useCustomerPortal.ts`:**
```typescript
// POST /billing/portal-session { returnUrl: window.location.href }
// Returns { url: string }
// window.location.href = url
```
- Loading state on button while request is in flight

**Handle Stripe Portal return:**
- User returns to `/app/settings/billing`
- Call `queryClient.invalidateQueries(['billing'])` and `queryClient.invalidateQueries(['entitlements'])` on page mount if `?portal_return=true` in URL

## Agent Notes

- Stripe Customer Portal is a full page redirect — same pattern as Checkout.
- Do NOT rebuild Stripe's portal UI (invoice list, payment method form, etc.).
- The `cancelAtPeriodEnd` warning is important — users who cancelled expect their Pro features until period end. The UI must reflect this accurately.
- On portal return, always refresh both billing status and entitlements — a cancellation or reactivation in the portal must be reflected immediately.
