# FE-015 — Dashboard Page

**Epic:** APP SHELL  
**Priority:** P0  
**Status:** NOT_STARTED  
**Parallel-safe:** NO — depends on FE-001, FE-004, FE-005, FE-012  

---

## Product Requirement

The dashboard is the authenticated home screen. It communicates the detective's current state, the highest-priority discoveries, and the user's potential value — all at a glance. It must not look like Gmail. The primary question it answers: "Is there anything I should know or do right now?"

## Current State

`src/pages/DashboardPage.tsx` is a placeholder from FE-003.

## Target State

- Dashboard renders agent status, top discoveries, and summary stats
- Personalized greeting uses user name from `AuthContext`
- High-importance discoveries shown as `DiscoveryCard` components
- Stat cards for money found, subscriptions, needs attention
- Translated in EN and ES

## Scope

**Implement `src/pages/DashboardPage.tsx`:**

Layout sections:
1. **Greeting** — "Good morning, {name}." (use time-of-day logic) from `useAuth().user.name`
2. **Detective Status** — `AgentStatusBadge` (inline, not in sidebar)
3. **Summary Stats row** — 3 × `StatCard`:
   - Money found: `formatCurrency` of total potential value
   - Subscriptions detected: count
   - Needs attention: high-importance count
   (stats derived from `GET /discoveries` summary metadata)
4. **Priority discoveries** — top 3–5 high-importance `DiscoveryCard` components
   - Action handlers: same as `DiscoveriesPage` (dismiss, remind via RequiresPro, etc.)
5. **"See all discoveries"** link → `/app/discoveries`
6. **Pro briefing section** (Pro only via `RequiresPro`):
   - Wrapped in `<RequiresPro feature="dailyBriefing">` 
   - Shows briefing content or upgrade prompt

**Create `src/hooks/useDashboard.ts`:**
```typescript
// GET /discoveries?importance=high&limit=5
// Returns top priority discoveries + summary metadata
```

**Time-of-day greeting logic** (`src/lib/greetingHelpers.ts`):
- Morning / Afternoon / Evening keys in `common.json`
- Based on `new Date().getHours()`

## Agent Notes

- The greeting must use `t('common.greeting.morning', { name: user.name })` with interpolation — not string concatenation.
- StatCard values use `formatCurrency` for money values and `formatNumber` for counts.
- Do NOT fetch discovery detail from this page — only the summary list. Full detail is on `DiscoveryDetailPage`.
- Dashboard is `/app/dashboard` — it is the default redirect for authenticated users (FE-003).
- The Pro briefing section is a placeholder `<RequiresPro>` wrapper in V1. Full Daily Briefing content comes in a future ticket.
