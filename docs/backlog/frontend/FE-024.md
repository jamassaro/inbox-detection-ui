# FE-024 — Account Deletion Flow

**Epic:** SETTINGS  
**Priority:** P1  
**Status:** NOT_STARTED  
**Parallel-safe:** NO — depends on FE-003, FE-005, FE-023  

---

## Product Requirement

Users must be able to delete their account and all imported data. The flow must be deliberate — accidental deletion must be impossible. Privacy regulations require this capability. It is distinct from "Disconnect Gmail" (which only removes OAuth access, not data).

## Current State

No account deletion flow exists.

## Target State

- Account deletion accessible from Settings
- Multi-step confirmation: explain consequences → type "delete" to confirm → execute
- After deletion: logout + redirect to `/`
- Translated in EN and ES

## Scope

**Create `src/pages/settings/DeleteAccountPage.tsx`** (or implement as a modal from SettingsPage):
- Step 1: "This will permanently delete your account and all imported email data. This cannot be undone."
  - Bullet list of what will be deleted
  - [Continue to deletion] (secondary style, not red yet)
  - [Cancel] → back to settings
- Step 2: Type confirmation input — `<input>` where user must type "delete" (lowercase, translated for ES: "eliminar")
  - [Delete my account] (red/destructive) — disabled until input matches
- Loading state: "Deleting your account..."
- Success: toast + redirect to `/`
- Error: "Account deletion failed. Please contact support." + support email link

**Create `src/hooks/useDeleteAccount.ts`:**
```typescript
// DELETE /account { confirmation: 'delete' }
// On success: AuthContext.logout() equivalent (clear state) + navigate to '/'
```

**Update `src/pages/settings/SettingsPage.tsx`** (FE-023):
- Add [Delete account and data] link at bottom of Account section
- Visually distinct from other links (red text or subdued)

## Agent Notes

- The confirmation word in Spanish is "eliminar" — NOT "delete". Use a translation key `t('settings.deleteAccount.confirmWord')` and compare the input against that value.
- After successful deletion, do NOT use `AuthContext.logout()` (which calls `POST /auth/logout` — the account may already be gone). Instead: clear the auth context state locally and navigate to `/`.
- This is a rare but high-stakes flow. Prioritize clarity over visual density. Use plenty of whitespace and clear destructive styling.
