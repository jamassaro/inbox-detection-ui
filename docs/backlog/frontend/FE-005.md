# FE-005 — Shared UI Primitives

**Epic:** APP SHELL  
**Priority:** P0  
**Status:** NOT_STARTED  
**Parallel-safe:** NO — depends on FE-002 (for translations); blocks most feature tickets  

---

## Product Requirement

Every feature screen needs loading states, empty states, error states, modals, toasts, and skeletons. Without shared primitives, each feature ticket invents its own, creating inconsistent UX and duplicated code. These must exist before feature tickets begin.

## Current State

No shared UI primitives exist. No loading components, no skeleton cards, no empty states, no error states, no toast system, no modal base.

## Target State

A complete set of shared UI primitives in `src/components/` that all feature tickets can import and use. All copy uses `useTranslation()`.

## Scope

**`src/components/LoadingSpinner.tsx`**
- `size?: 'sm' | 'md' | 'lg'` prop
- CSS animation, no external library
- `aria-label` translated

**`src/components/SkeletonCard.tsx`**
- Animated gray skeleton for card-shaped loading placeholders
- `lines?: number` prop
- Used while TanStack Query is loading

**`src/components/SkeletonListItem.tsx`**
- Animated gray skeleton for list row loading placeholders

**`src/components/EmptyState.tsx`**
```tsx
interface EmptyStateProps {
  icon?: LucideIcon;
  title: string;       // translated string passed as prop
  description?: string;
  action?: { label: string; onClick: () => void };
}
```

**`src/components/ErrorState.tsx`**
```tsx
interface ErrorStateProps {
  title?: string;
  description?: string;
  onRetry?: () => void;
}
```
- Default title from `errors.generic` translation key
- Shows retry button when `onRetry` provided

**`src/contexts/ToastContext.tsx`** + **`src/hooks/useToast.ts`**
- `toast.success(message)`, `toast.error(message)`, `toast.info(message)`
- Max 3 visible toasts, auto-dismiss after 4 seconds
- Renders in a fixed portal at bottom-right
- `role="status"` for screen readers

**`src/components/Modal.tsx`**
- Base modal with focus trap, ESC to close, backdrop click to close
- `isOpen`, `onClose`, `title`, `children` props
- Accessible: `role="dialog"`, `aria-modal`, `aria-labelledby`

**`src/components/ConfirmModal.tsx`**
- Wraps `Modal`
- `message`, `confirmLabel`, `cancelLabel`, `onConfirm`, `onCancel`, `variant?: 'default' | 'destructive'`
- Destructive variant: confirm button is red

**`src/components/ActionButton.tsx`**
- Standardized button variants: `'primary' | 'secondary' | 'destructive' | 'ghost'`
- `isLoading?: boolean` shows spinner inline
- `size?: 'sm' | 'md' | 'lg'`
- All existing hardcoded `<button className="bg-gray-900...">` buttons should be replaceable with this

**Update `src/main.tsx`:**
- Add `<ToastProvider>` wrapper

## Agent Notes

- `Modal` focus trap: use `document.querySelector('[data-modal-content]')` + `focusable elements` selector. Do NOT install a focus-trap library — a simple implementation is sufficient.
- `ToastContext` renders toasts in a React portal (`document.body`) to avoid z-index issues.
- `ActionButton` should support `as` prop or `href` for link buttons where needed — but keep it simple, don't over-engineer.
- Skeleton animation should use Tailwind `animate-pulse` — no custom CSS.
- Do NOT use `React.forwardRef` unless genuinely needed — keep components simple.
