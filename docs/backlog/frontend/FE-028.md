# FE-028 — Responsive Audit + Mobile Fixes

**Epic:** RESPONSIVE  
**Priority:** P1  
**Status:** NOT_STARTED  
**Parallel-safe:** NO — depends on most UI tickets being complete  

---

## Product Requirement

Production V1 must work on desktop, tablet, and mobile. Spanish strings are longer than English. The current prototype has a fixed-width sidebar and desktop-only layouts. P0 responsive issues must be fixed before launch.

## Current State

The prototype has a fixed `w-48` sidebar, `grid-cols-2` card grids, fixed `w-80` search input, and `h-screen` layout. None of these adapt to mobile. The `max-w-5xl px-8` content padding is excessive at mobile widths.

## Target State

- App shell is usable at 375px (mobile), 768px (tablet), and 1440px (desktop)
- Sidebar collapses to a hamburger/drawer on mobile
- All card grids wrap correctly
- Content padding appropriate at all breakpoints
- Spanish string overflow does not break layouts
- `100dvh` replaces `100vh` where applicable

## Scope

**App Shell:**
- `Sidebar` at `md:` and below: collapse to an off-canvas drawer
- Add hamburger menu button in `AppLayout` mobile header
- Drawer opens on hamburger click, closes on nav item click or backdrop click
- All existing nav links work in drawer mode

**Content Areas:**
- `max-w-5xl px-8` → `max-w-5xl px-4 sm:px-8` (reduce mobile padding)
- `grid-cols-2` featured cards → `grid-cols-1 sm:grid-cols-2`
- `w-80` search input → `w-full sm:w-80`
- All fixed-width buttons → `w-full sm:w-auto` where appropriate

**Layout:**
- Replace `h-screen` / `min-h-screen` with `h-dvh` / `min-h-dvh` where applicable (handles mobile browser chrome resize)

**Spanish overflow audit:**
- Test all button labels, nav labels, pricing card copy, Discovery action buttons in Spanish
- Fix any overflow: use `truncate`, `text-sm`, flex-wrap, or min-width adjustments

**Specific screens to audit:**
- Landing page (all sections)
- Dashboard
- Discoveries list
- Discovery detail
- Investigation progress
- Upgrade/Billing pages
- Settings
- Chat

## Out of Scope

- Native app-like mobile navigation patterns
- Tablet-optimized layouts (tablet uses desktop layout)
- PWA manifest
