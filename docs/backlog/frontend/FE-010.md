## Product Requirement

The app shell is the persistent chrome visible on every authenticated screen. The current Sidebar has hardcoded text, a non-functional "Scan Inbox" button, and a hardcoded "Connected" status. It needs real navigation, real Gmail status, an agent status indicator, and the language selector.

## Current State

`src/components/Sidebar.tsx` — 80 lines, functional nav shell with hardcoded labels, hardcoded "Connected" text, non-functional "Scan Inbox" button, links to dead routes (`/companies`, `/saved`). `src/components/AppLayout.tsx` was created as a stub in FE-003.

## Target State

- Sidebar shows correct nav items for Production V1
- Gmail connection status is real (from `useGmailStatus()`)
- "Scan Inbox" / "Investigating..." button is wired to trigger an investigation
- `AgentStatusBadge` shows detective state
- `LanguageSelector` is in the sidebar footer
- All labels translated in EN and ES
