# FE-027 — DOMPurify Email Content Sanitization

**Epic:** PRODUCTION HARDENING  
**Priority:** P0  
**Status:** DONE — on `main` via #2 (verified 2026-09-17)  
**Parallel-safe:** YES — standalone dependency install and utility, no conflicts  

---

## Product Requirement

Inbox Detective renders email content as evidence inside the `EmailDrawer`. Email HTML is attacker-controlled content — if rendered unsanitized it is an XSS vector. Sanitization with DOMPurify is a P0 security requirement.

## Current State

`dompurify` is not installed. No sanitization utilities exist. `EmailDrawer` does not yet exist (FE-014 creates it) but must use sanitization when it does.

## Target State

- `dompurify` and `@types/dompurify` installed
- A `sanitizeHtml(html: string): string` utility in `src/lib/sanitize.ts`
- DOMPurify configured with a restrictive allowlist
- Any future component rendering email HTML must use this utility

## Scope

**Install:**
```
dompurify
@types/dompurify
```

**Create `src/lib/sanitize.ts`:**
```typescript
import DOMPurify from 'dompurify';

const ALLOWED_TAGS = [
  'p', 'br', 'b', 'i', 'em', 'strong', 'span', 'div',
  'ul', 'ol', 'li', 'a', 'blockquote'
];
const ALLOWED_ATTR = ['href', 'target', 'rel'];

export function sanitizeHtml(html: string): string {
  return DOMPurify.sanitize(html, {
    ALLOWED_TAGS,
    ALLOWED_ATTR,
    // Force external links to open safely
    FORCE_BODY: true,
  });
}
```

All `<a>` tags output by sanitizer must have `rel="noopener noreferrer"` and `target="_blank"` added.

**Add a post-process step** for links:
```typescript
export function sanitizeEmailHtml(html: string): string {
  const clean = sanitizeHtml(html);
  // Ensure all links are safe external links
  return clean.replace(/<a /g, '<a target="_blank" rel="noopener noreferrer" ');
}
```

## Out of Scope

- Sanitizing non-email content
- Sanitizing backend API responses beyond email HTML
- EmailDrawer itself (FE-014)

## Dependencies

None. This is a standalone utility.

## Agent Notes

- Never render email content with `dangerouslySetInnerHTML={{ __html: rawEmail }}`. Always pipe through `sanitizeEmailHtml` first.
- The `ALLOWED_TAGS` list is intentionally restrictive. Do not allow `<script>`, `<style>`, `<iframe>`, `<form>`, `<input>`, `<img>` (unless needed — if backend provides sanitized excerpts, img may not be needed at all).
- DOMPurify requires a DOM environment. This is available in the browser. For tests, jsdom (configured in Vitest) provides the DOM. No special test configuration needed.
