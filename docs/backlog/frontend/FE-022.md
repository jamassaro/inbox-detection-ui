## Product Requirement

Detective Chat lets users ask natural language questions about their inbox. Free users have a limited number of questions. Pro users have broader access. Chat responses may reference Discoveries and source emails. The Detective must respond in the user's selected UI language.

## Current State

`src/pages/ChatPage.tsx` is a placeholder from FE-003. No chat functionality exists.

## Target State

- Chat interface with message list, input, and loading state
- Free limit counter (from entitlements)
- Discovery references render as inline `DiscoveryCard` (compact) within responses
- Source email references open `EmailDrawer`
- Backend Chat responds in user locale via `Accept-Language` header (already set by `apiClient`)
- Translated in EN and ES

## Scope

**Create `src/hooks/useChat.ts`:**
```typescript
function useChat() {
  // POST /chat/messages { message } → { answer: string, sources: ChatSource[] }
  // GET /chat/messages → ChatMessage[] (history)
  // Returns { messages, send, isLoading, error }
}
interface ChatSource {
  type: 'discovery' | 'email';
  discoveryId?: string;
  emailId?: string;
  label: string;
}
interface ChatMessage {
  id: string;
  role: 'user' | 'detective';
  content: string;          // AI-generated — render as-is
  sources?: ChatSource[];
  timestamp: string;
}
```

**Implement `src/pages/ChatPage.tsx`:**

Layout:
```
┌──────────────────────────────────┐
│  Ask Detective                   │
├──────────────────────────────────┤
│  [suggested prompts if empty]    │
│                                  │
│  [user message]                  │
│  [detective response]            │
│    └─ [inline discovery ref]     │
│    └─ [source chip]              │
│                                  │
├──────────────────────────────────┤
│  [limit counter for Free]        │
│  [message input]    [Send]       │
└──────────────────────────────────┘
```

- Empty state: grid of 4–6 suggested prompts (translated, from `detective.chat.suggestions.*`)
  - Clicking a suggestion fills the input
- User messages: right-aligned gray bubble
- Detective responses: left-aligned white card with subtle border
  - `content` rendered as-is (AI-generated in user's locale)
  - Discovery references: compact `DiscoveryCard` (pass `compact={true}` prop)
  - Source chips: `"Source: Adobe email, Sep 14"` — click opens `EmailDrawer`
- Loading: "Detective is thinking..." animated (from `detective.chat.states.thinking`)
- Free limit counter: `"{{remaining}} of {{total}} questions remaining"` (interpolation)
  - When limit reached: input disabled, upgrade prompt shown in footer
  - `<RequiresPro feature="chatAccess">` wraps input area
- Error: inline `ErrorState` with retry

**Chat history:**
- Load on mount via `GET /chat/messages`
- Scroll to bottom on new message
- `SkeletonListItem` × 3 while loading history

## Agent Notes

- Chat `content` is AI-generated — the backend responds in the user's locale via `Accept-Language`. Do NOT translate it in the frontend.
- Suggested prompts are static frontend copy — these SHOULD be in translation files: `t('detective.chat.suggestions.subscriptions')`, etc.
- `chatQuestionsRemaining` from `useEntitlements()` is the source of the limit counter. `null` = unlimited (Pro).
- Do NOT stream response text for V1 — await the full `POST /chat/messages` response before rendering.
- Scroll behavior: after each new message, scroll the message list container to the bottom. Use `useEffect` + `ref.current.scrollTop = ref.current.scrollHeight`.
