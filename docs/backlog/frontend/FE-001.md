## Product Requirement

Every authenticated screen fetches real data from the backend. The application needs a centralized, type-safe API client and a server-state caching layer before any feature work begins. Without this foundation, every subsequent ticket would invent its own fetch/cache pattern, making the codebase unmaintainable.

## Current State

`package.json` has only four runtime dependencies: `lucide-react`, `react`, `react-dom`, `react-router-dom`. There is no API client, no query client, no HTTP abstraction. `src/data/mockOffers.ts` is the only data source.

## Target State

- TanStack Query v5 installed and configured with a `QueryClient`
- A centralized `apiClient` that attaches the session cookie, handles 401 by clearing auth state, and forwards `Accept-Language` from the active locale
- App root wrapped with `QueryClientProvider`
- Vitest + React Testing Library installed (needed by all subsequent test tasks)

## Scope

- Install: `@tanstack/react-query`, `vitest`, `@vitest/ui`, `@testing-library/react`, `@testing-library/user-event`, `jsdom`
- Create `src/lib/queryClient.ts` — export a singleton `QueryClient` with sensible defaults (staleTime 1 min, retry 1)
- Create `src/lib/apiClient.ts` — `apiFetch(path, options)` wrapper:
  - Base URL from `import.meta.env.VITE_API_BASE_URL`
  - Includes credentials: `'include'` (session cookie)
  - Sets `Content-Type: application/json`
  - Sets `Accept-Language` from `localStorage.getItem('inbox-detective-locale') ?? 'en'`
  - On 401: dispatches a custom `auth:expired` window event (consumed by AuthContext in FE-003)
  - Throws a typed `ApiError` with `{ status, code, message }` on non-2xx responses
- Create `src/lib/apiError.ts` — `ApiError` class
- Update `src/main.tsx` — wrap `<App />` with `<QueryClientProvider client={queryClient}>`
- Add `vitest.config.ts` with jsdom environment
- Add `"test": "vitest"` and `"test:ui": "vitest --ui"` to `package.json` scripts
- Create `src/lib/__tests__/apiClient.test.ts` — unit tests for error handling and header injection

## Out of Scope

- AuthContext (FE-003)
- Any real API calls
- Route changes
- Environment variable files (`.env.example` is acceptable; never commit `.env`)

## Agent Notes

- `VITE_API_BASE_URL` must be read from `import.meta.env` — never hardcoded. If undefined, `apiFetch` should throw a clear error in development.
- Do NOT use `axios`. Use native `fetch`.
- Do NOT add `react-query-devtools` to production bundle — use dynamic import gated on `import.meta.env.DEV`.
- `tsconfig.app.json` has `noUnusedLocals: true` — do not leave unused imports.
- The `auth:expired` event pattern decouples the API layer from AuthContext and avoids circular imports.
- Keep `queryClient.ts` minimal — no custom retry logic beyond `retry: 1`.
