# FE-006 — Landing Page

**Epic:** PUBLIC  
**Priority:** P0  
**Status:** NOT_STARTED  
**Parallel-safe:** NO — depends on FE-002 (i18n), FE-003 (router)  

---

## Product Requirement

`/` must always be public, even for authenticated users. It is the product's first impression and the primary conversion funnel entry point. It must communicate the product's value clearly in English and Spanish and drive users toward "Investigate my inbox."

Primary headline: **"Your inbox knows things you don't."**  
Spanish: **"Tu bandeja de entrada sabe cosas que tú no."**  
Primary CTA: **"Investigate my inbox"** / **"Investigar mi bandeja"**

## Current State

`src/pages/LandingPage.tsx` is a placeholder created by FE-003 (returns a minimal div). No real landing page content exists. The `index.html` title is "inbox-detection-ui".

## Target State

A complete public landing page at `/` with full marketing content in EN and ES. The `LanguageSelector` component is visible in the public nav. Authenticated users can visit `/` without being redirected.

## Scope

**Implement `src/pages/LandingPage.tsx`** with these sections:
1. **Navigation bar** — "Inbox Detective" brand, `LanguageSelector`, "Sign in" link (→ triggers auth flow), "Investigate my inbox" CTA
2. **Hero** — Primary headline, subtitle, primary CTA button, trust line ("Connect Gmail. See what you've been missing.")
3. **Problem** — What gets missed in email (subscriptions, price changes, credits, meetings)
4. **Discovery Examples** — 3 sample discovery cards (static, no real data) illustrating the product
5. **How It Works** — Connect → Investigate → Discover → Act
6. **Free Investigation** — What the free tier delivers
7. **Agent Capabilities (Pro)** — Continuous monitoring, reminders, calendar, chat
8. **Free vs Pro Comparison** — Side-by-side or table format
9. **Pricing** — Free ($0) / Pro ($5.99/month, $49/year) with Stripe as source of truth messaging
10. **FAQ** — 4–6 questions from `public.faq.*` translation keys
11. **Final CTA** — Repeat primary CTA
12. **Footer** — Privacy Policy link, Terms link, copyright

**Update `index.html`:**
- `<title>Inbox Detective</title>`
- Add `<meta name="description">` with translated content

**Navigation behavior:**
- If authenticated (`useAuth().isAuthenticated`): "Sign in" → "Go to app" (→ `/app/dashboard`)
- If not authenticated: "Sign in" / "Investigate my inbox" → Google OAuth (calls `GET /auth/google`, see FE-007)
- Landing page remains accessible to both

All copy via `useTranslation('public')` namespace.

- Blog, changelog, or help docs

## Agent Notes

- The landing page should be a single-file component but keep sections as local sub-components (e.g., `HeroSection`, `PricingSection`) to keep the file readable. Do not create separate files for landing sub-sections.
- Discovery example cards are static content — do NOT connect to an API. Use hardcoded translation keys for the examples.
- Pricing amounts ($5.99, $49) are presentational only. Never hardcode entitlement logic. The actual Stripe product/price configuration is the source of truth.
- `LanguageSelector` imported from `src/components/LanguageSelector.tsx` (created in FE-002).
- The nav "Sign in" / "Investigate my inbox" CTA will navigate to a Google auth URL. For now, link to `GET /auth/google` which the backend provides as a redirect. FE-007 implements the full flow.
- Spanish text in pricing section: "$5.99/mes", "$49/año" — use `billing.frequency.monthly` / `billing.frequency.annual` from translation files.
