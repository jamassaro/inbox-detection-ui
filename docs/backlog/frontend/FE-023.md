# FE-023 — Settings Page

**Epic:** SETTINGS  
**Priority:** P0  
**Status:** NOT_STARTED  
**Parallel-safe:** NO — depends on FE-003, FE-004, FE-005, FE-008  

---

## Product Requirement

Users need a single place to manage their account, connected services, and billing. The current `/settings` route renders an inline placeholder div. V1 must provide working account management, Gmail status + disconnect, Calendar status + disconnect, and billing navigation.

## Current State

`src/pages/settings/SettingsPage.tsx` is a placeholder from FE-003. Route `/app/settings` exists but renders nothing meaningful.

## Target State

- Settings page with Account, Connected Accounts, and Billing sections
- Gmail status visible with disconnect option
- Calendar status visible with connect/disconnect option
- Billing section links to BillingPage
- LanguageSelector available in settings
- Logout works
- Translated in EN and ES

## Scope

**Implement `src/pages/settings/SettingsPage.tsx`:**

Sections:

**Account**
- User name, email (read-only, from `AuthContext`)
- `LanguageSelector` (reuse from FE-002)
- [Log out] button → `AuthContext.logout()`
- [Delete account] link → `/app/settings/delete` (FE-024)

**Connected Accounts**

Gmail row:
- Status: "Gmail connected: [email]" with green dot OR "Not connected" with gray
- "Last synced: [time]" (from `useGmailStatus()`)
- If connected: [Disconnect Gmail] → `ConfirmModal` → `DELETE /gmail/connection` → redirect to `/onboarding`
- If not connected: [Connect Gmail] → `/onboarding`

Calendar row:
- Status: "Google Calendar connected" OR "Not connected"
- If connected: [Disconnect Calendar] → `ConfirmModal` → `DELETE /calendar/connection`
- If not connected: [Connect Calendar] → `GET /calendar/connect` (only shown for Pro users via `RequiresPro`)

**Billing**
- "Current plan: Free / Pro" (from entitlements)
- [Manage billing] → navigate to `/app/settings/billing`

**Privacy**
- Link: "Privacy Policy" → `/privacy`
- Link: "Terms of Service" → `/terms`

**Create `src/hooks/useDisconnectGmail.ts`:**
```typescript
// DELETE /gmail/connection → { ok }
// On success: invalidate gmail-status query, navigate to /onboarding
```

**Create `src/hooks/useDisconnectCalendar.ts`:**
```typescript
// DELETE /calendar/connection → { ok }
// On success: invalidate calendar-status query
```

## Agent Notes

- Disconnect confirmation copy must be specific: "Disconnecting Gmail will stop all monitoring and investigations. Your existing data is not deleted." Not just "Are you sure?"
- After Gmail disconnect: `navigate('/onboarding')` because the user must reconnect to use the app.
- After Calendar disconnect: stay on settings page, refresh calendar status.
- `LanguageSelector` in settings switches language immediately. This is a good test of the i18n system — the page should re-render in the new language without navigation.
